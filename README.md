# 📰 MZ News & Article

**Your World, Your News.**

MZ News & Article is a modern, responsive news website designed to deliver news articles through a clean, user-friendly interface. The project focuses on readable content, organized news layouts, and a professional browsing experience across different devices.

## 🌟 Overview

MZ News & Article aims to provide a simple and engaging platform for browsing news content. Its visual identity combines a bold news brand, a global news theme, and multilingual representation to create a recognizable digital news experience.

## ✨ Features

- **Modern UI Design** – Clean, professional, and visually appealing interface.
- **Responsive Layout** – Designed to adapt to desktop, tablet, and mobile screens.
- **News Article Layout** – Structured presentation for readable news content.
- **Multilingual Branding** – Visual representation of Tamil, English, Hindi, Telugu, and Malayalam.
- **User-Friendly Experience** – Simple navigation and clear content presentation.
- **Professional Branding** – Custom MZ News & Article identity and OG image design.
- **Cross-Device Compatibility** – Built with responsive web design principles.

## 🛠️ Tech Stack

- **HTML5** – Website structure and semantic content.
- **CSS3** – Styling, layouts, and responsive design.
- **JavaScript** – Interactive functionality, where implemented.
- **Git & GitHub** – Version control and source code management.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- Live Server extension (optional).

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd MZ-News-Article
```

**3. Open the project**

Open the project folder in Visual Studio Code.

**4. Run the website**

Open `index.html` in your browser or use the Live Server extension for local development.
